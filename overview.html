Project Overview

A complete look at the planning, design and development of Coaching Hub, including our objectives, design decisions and AI usage.

1. About the Project

Website Title: Coaching Hub

Website Category: Educational Website

Coaching Hub is a fitness website that brings coaching, nutrition and training resources together in one place.

2. Problem Statement

Many people struggle to find suitable coaches, reliable fitness information and training programmes. Coaching Hub aims to make these resources easier to access.

3. Project Objectives

  • Help users discover suitable coaches
  • Provide training programmes and guidance
  • Educate users about nutrition and supplements
  • Provide interactive fitness calculators
  • Create a responsive and user-friendly website

4. Target Audience

The website is designed for fitness beginners, gym members, athletes and individuals looking to improve their fitness or manage their weight.

      Design Decisions

      • Warm colours create a welcoming appearance.
      • Natural images support the Mediterranean theme.
      • Shared stylesheets maintain visual consistency.
      • Grid and Flexbox organise website content.
      • Responsive layouts support different devices.

      Responsive Design Plan

      Coaching Hub is designed to adapt to different screen sizes using CSS media queries.

      Desktop

      Full navigation and multi-column layouts make use of wider screens.

      Tablet

      Reduced spacing and adjusted columns provide comfortable viewing.

      Mobile

      Collapsible navigation and stacked content improve usability on smaller screens.
