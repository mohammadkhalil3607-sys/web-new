Project Reflection & AI Evaluation

Our development journey and learning experience

1. Project Reflection and Goals

Coaching Hub is a website that allows people to access coaching services and also education relating to training and nutrition. It contains tools that can predict relevant fitness information and also details on nutritional products. We wanted to create a user-friendly, interactive and adaptable site incorporating HTML, CSS and JavaScript and aimed it at sportspeople, new exercisers and those who wish to control their weight.

2. Development and Technical Challenges

We were given a reference design to show us the general style which should be implemented. The original color scheme, hero and card designs, however, had not fulfilled our vision; so we redesigned the website using the given reference and assessment criteria.

CSS grid was used for card and page layout and flexbox was used to centre the navigation bar. One person developed CSS templets and color schemes thus decreasing repetition and ensuring that all pages followed the same style.

At times, team members attempted to upload work to GitHub at the same time and therefore Subtopic 1 was overwritten. By analysing the Git history we were able to identify and fix the incorrect code. Successfully navigating these problems enhanced our knowledge of responsive, styled and version controlled websites.

3. AI Utilisation and Critical Evaluation

Throughout this project AI was used. ChatGPT recommended that we should switch from our original dark colour scheme to something more bright and user friendly in style. AI was also used to produce images, logos and icons. It was incorporated into our collaborative space and was used to help describe the mathematics that is present on the ‘Nutrition’ page.

AI on at times produced inaccurate links, and images of incorrect file types. Furthermore, it had made inappropriate recommendations for the ‘Reflection’ page border; we reverted back to our original card design.

Claude Code was employed to investigate the structure of both the ‘Home’ page menu and footer. This then enabled team members to apply uniform page templates.

It has been shown that AI can speed up a project. However, there is a need to assess and modify its work.

4. Team Collaboration Experience

Tasks were divided between the four people in the group. Ali Basheer created the Homepage, Subtopic 1 and produced common CSS and also a repository, which contained all of our resources and set out details regarding both assessment and production.

Mohammed Khalil restructured the main site and created Subtopic 2. He also assisted with enhancing the Reflection and Overview pages. Yousef was in charge of the Training and Planning and Design pages. Mohammed Jassim constructed the original Reflection & AI Report and Overview pages.

It was the role of the group leader to bring everyone’s work together. Even though the task division had aided our team work, a more structured approach, together with more frequent evaluation sessions, would have further enhanced our efficiency.

5. Lessons Learned and Future Improvements

We developed our knowledge of HTML tags, CSS and linear gradient styling. Furthermore, we enhanced our knowledge of JavaScript and used this to add mathematical and conditional functionality to further improve the sites interactivity.

We also utilised AI in the creation, examination and documentation of code. GitHub was a useful tool for showing the value of version control and working in a team. Testing was also emphasized as a key element of site creation in relation to the assessment criteria.

Going forwards, we will set more specific project phases, regularly evaluate the assessment criteria and create distinct Git branches to avoid issues arising. Furthermore, additional time will be dedicated to testing for responsiveness. These steps will further promote team working and ensure greater uniformity and dependability in our website.
